CSS: Селекторы и специфичность

Краткое руководство по выбору элементов и приоритету стилей

1. Типы селекторов

Селектор Синтаксис Что выбирает
Универсальный * Все элементы
По тегу div, p Все элементы указанного типа
По классу .btn Все элементы с данным классом
По ID #header Один элемент с данным ID
По атрибуту [type="text"], [href] Элементы с указанным атрибутом

2. Комбинаторы

Комбинатор Синтаксис Смысл
Пробел (потомок) div p Все p внутри div на любом уровне вложенности
> (прямой потомок) div > p Только p, непосредственный ребёнок div
+ (соседний) h1 + p Первый p, идущий сразу после h1
~ (общий сосед) h1 ~ p Все p, идущие после h1 на том же уровне

3. Псевдоклассы и псевдоэлементы

Псевдоклассы (состояние элемента)

  • :hover, :focus, :active
  • :first-child, :last-child, :nth-child(n)
  • :not(.class)

Псевдоэлементы (часть элемента)

  • ::before, ::after — генерируемое содержимое
  • ::first-line, ::first-letter

4. Специфичность (вес селектора)

Браузер вычисляет вес каждого селектора как кортеж (a, b, c):

Компонент Что даёт Пример
a Количество ID #header → (1, 0, 0)
b Количество классов, атрибутов, псевдоклассов .btn, [type], :hover
c Количество тегов и псевдоэлементов div, ::before
Важно: Универсальный селектор * и комбинаторы (>, +, ~, пробел) вес не добавляют.

Примеры расчёта

Селектор a b c Итог
div 0 0 1 (0, 0, 1)
.container 0 1 0 (0, 1, 0)
#main 1 0 0 (1, 0, 0)
div.container 0 1 1 (0, 1, 1)
#main .nav a:hover 1 2 1 (1, 2, 1)
Правило сравнения: Селекторы сравниваются поразрядно слева направо: сначала a, потом b, потом c.
11 классов (0, 11, 0) не перебьют 1 ID (1, 0, 0).

5. Порядок применения стилей (каскад)

Если несколько правил претендуют на один элемент, браузер применяет их в таком порядке приоритета (от низшего к высшему):

  1. Стили браузера по умолчанию (user agent stylesheet)
  2. Стили пользователя (настройки браузера)
  3. Стили автора (ваш CSS) — с учётом специфичности
  4. При равной специфичности — побеждает правило, написанное ниже в коде (последнее)
  5. Инлайн-стили (style="..." в теге) — вес (1, 0, 0, 0), выше любого селектора
  6. !important — перебивает всё, включая инлайн (если оба с !important — снова решает специфичность)

6. Наследование

Не все CSS-свойства наследуются от родителя.

Наследуются по умолчанию:

color, font-family, font-size, line-height, text-align, visibility, cursor

Не наследуются:

margin, padding, border, background, width, height, display, position

Принудительно унаследовать: property: inherit;
Сбросить к значению по умолчанию: property: initial;
Взять значение из браузера: property: revert;

7. Практические правила

  • Используй классы как основной инструмент стилизации
  • ID в селекторах CSS — плохая практика: высокий вес, невозможно переиспользовать, сложно переопределить
  • Избегай длинных цепочек вложенности (div.container ul li a span) — хрупко и тяжело поддерживать
  • !important — только для отладки или переопределения сторонних библиотек. В своём коде не использовать
  • Для сброса стилей браузера применяй * { margin: 0; padding: 0; box-sizing: border-box; } в начале файла
